# Clarify Intent

## Method

1. Read the Handoff and supplied context. Investigate facts that can be established from available sources; do not turn checkable facts into user questions.
2. Separate established facts, working assumptions, and decisions only the user can make.
3. Rank unresolved decisions by how much each could change scope, behavior, risk, cost, or success criteria.
4. For each material decision, formulate one concise question with concrete options, a recommended default when evidence supports one, and the consequence of each option.
5. Build a confirmation-ready consensus containing only established or explicitly supplied decisions. Keep unsupported assumptions visibly separate.

## Output

Report:

- established facts and their evidence;
- unresolved decisions in priority order;
- proposed question, options, recommendation, and impact for each decision;
- a draft consensus or the exact reason consensus is not yet possible.

Do not ask the user directly, infer a user preference, design the solution, or perform implementation. The Router owns user interaction and subsequent routing.
