## Ownership and precedence

The PRD owns product intent and scope. If accepted, the ADR constrains the Spec; if accepted, the Spec constrains Plan and Tasks. Work, Context, Plan, and Tasks are derived coordination material, not authority or acceptance evidence.

A clean fresh independent review must precede one later consolidated user confirmation for the complete PRD, ADR, Spec, Plan, and Tasks set. No wording, message count, UI, command, or confirmation mechanism is prescribed here.
